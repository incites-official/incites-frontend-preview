# INCITES Frontend

Next.js App Router 기반의 INCITES 운영 화면입니다.

## 실행

백엔드를 먼저 `http://localhost:8080`에서 실행한 뒤 다음 명령을 사용합니다.

```bash
npm install
npm run dev
```

화면은 `http://localhost:3000`에서 열립니다. 백엔드 주소가 다르면 환경 변수를 설정합니다.

```bash
NEXT_PUBLIC_API_BASE_URL=http://localhost:8080 npm run dev
```

장시간 미사용 자동 로그아웃은 기본 30분이며 `NEXT_PUBLIC_IDLE_TIMEOUT_MINUTES`로 변경할 수 있습니다.

## 주요 동작

- 좌측 내비게이션과 상단 계정 영역으로 구성된 공통 애플리케이션 프레임
- 권한에 따른 메뉴 노출 및 페이지 접근 차단
- 총괄관리자와 일반관리자 실제 계정별 로그인 및 권한 분리
- 액세스 토큰 만료 시 한 번의 공동 재발급 후 원 요청 재시도
- 세션 만료, 자동 로그아웃, 권한 없음, 404 안내 화면 분리
- 대시보드 API 최초 1회 확인 및 사용자 수동 새로고침
- 관리자 전용 사용자 검색, 등록, 수정, 비밀번호 변경, 계정 사용 중지
- 학생 등록·수정·사용 중지, 담당 강사 배정, 보호자 연결 승인·거절
- 관리자·학부모 촬영 동의 변경 및 동의 이력 조회
- 교사 담당 학생 조회, 수업 생성, 관찰 기록 최종 저장, 30일 임시저장
- 관리자 관찰 기록 감사 조회와 교사 학생별 관찰 타임라인·역량 평균 표시
- 학부모 학생 코드 연결 요청, 승인된 자녀 목록 및 촬영 동의 관리
- 여러 탭 간 로그인 토큰과 로그아웃 상태 동기화
- 학생·학부모 역할별 모바일 전용 홈, 성장, 리포트, MY 화면
- 학생·학부모 인앱 알림 조회·읽음 처리와 알림 대상 리포트 바로 열기
- 학생·학부모 내 정보 및 비밀번호 변경, 성장 알림 수신 설정
- 학생·학부모 화면은 데스크톱에서도 390px 모바일 폼팩터 유지

## 역할별 알림 기능

- 총괄관리자(SA): 보호자의 자녀 연결 요청과 일반관리자가 등록한 새 관찰 기록을 상단 알림 메뉴에서 확인하고 관련 관리 화면으로 이동합니다.
- 일반관리자(GA): 담당 학생의 보호자 연결 승인·거절 결과를 확인하고 학생 성장 관리 화면으로 이동합니다.
- 학부모(PA): 자녀 연결 처리 결과, 새 관찰 기록, 관리자가 발송한 미열람 성장 리포트 알림을 확인합니다.
- 학생(ST): 본인의 새 관찰 기록과 성장 리포트 공개 알림을 확인합니다.
- 공통: 안 읽은 알림 표시, 항목별 읽음, 전체 읽음, 역할별 대상 화면 이동을 지원하며 알림 본문은 PC와 모바일 모두 최대 3줄로 표시합니다.

사진 파일 업로드, 월간 성장 리포트, 학부모·학생용 성장·관찰 조회, 역할별 대시보드와 시스템 설정까지 실제 백엔드 API에 연동되어 있습니다. 로컬 확인 시 MySQL의 `incites` 데이터베이스와 백엔드를 먼저 실행하고, 백엔드 기본 포트인 `8080`을 사용합니다.

시스템 설정 화면의 7대 역량과 톤앤매너·프롬프트 아이콘은 `public/settings` 아래의 원본 SVG를 직접 사용합니다. `next.config.ts`의 이전 주소 리다이렉트는 설정 페이지 경로에만 적용해 정적 SVG 요청과 충돌하지 않도록 구성했습니다.

로그인에는 가입 이메일을 사용하며, 이메일 찾기·비밀번호 재설정과 관리자 계정 발급 안내 메일을 지원합니다. Google·카카오 로그인은 인증 제공자 설정이 확정되지 않아 현재 지원하지 않으며, 버튼을 누르면 이 정책을 명시적으로 안내합니다.
